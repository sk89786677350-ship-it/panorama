# ПАНОРАМА

ПАНОРАМА — общая оболочка системы Сергея. Управление и подключаемые торговые марки/проекты расположены непосредственно под ней в одном ряду.

## Нижний ряд
- **Панорама управление** — закрытый центр владельца; Telegram-бот, голосовые задания, согласования, календари и отчёты.
- **Панорама Гефу** — отдельное пространство GEFU.
- **Панорама Валира** — отдельное пространство VALIRA.
- **Проект 12520** — самостоятельное подключаемое товарное направление GEFU, рядом с пространствами марок.
- Другие марки/проекты подключаются отдельно.

Проект 12520 сохраняет отдельный репозиторий [gefu-12520-landing](https://github.com/sk89786677350-ship-it/gefu-12520-landing). Здесь фиксируется его подключение; материалы и код лендинга не переносятся в ядро.

Торговые марки имеют разные сроки поставки, остатки, оборачиваемость и планы продвижения. Общие механизмы переиспользуются, но данные и подключения марок не смешиваются. Отключение марки не удаляет оболочку или управление.

## Первый сценарий
Голос/текст из Telegram на Android или Windows 10 → повтор задания → подтверждение владельца → подготовка материала → проверка → согласование готовой версии → публикация → ссылка и запись результата.

Задание и готовая публикация согласуются отдельно. Без явного разрешения готовой версии публикация запрещена. Неоднозначное «Да» не применяется к случайному заданию.

## Общие бизнес-объекты
Сохраняем согласованную основу ПАНОРАМЫ 1.0: юрлица, бренды, контрагенты с ролями клиент/поставщик, товары/услуги. Юрлицо и бренд — разные контуры; их связь может быть многие ко многим.

Общие функции: продажи, маркетинг/контент, операции, аналитика и PANORAMA Studio. Первым внедряем небольшой проверяемый процесс; полный набор модулей не разрабатываем одновременно.

Репозиторий закрытый. Токены, пароли, клиентские данные и внутренние ключи не включаются в файлы проекта.
