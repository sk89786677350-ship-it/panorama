# ПАНОРАМА — пошаговая реализация

Владелец — Сергей. Каждому этапу предшествует понятная инструкция; после результата — приёмка владельцем. Сейчас сохранение документации, а не запуск автоматизаций.

| Этап | Действия | Приёмка |
| --- | --- | --- |
| 1. Telegram-бот | Создать «Панорама управление» через @BotFather; предложенное username panorama_owner_control_bot, если свободно | Владелец присылает только @имя, не токен |
| 2. Сервер и доступ | Предложить конкретную конфигурацию/стоимость, безопасно подключить токен и Telegram ID владельца | Бот отвечает владельцу; чужая команда отклоняется |
| 3. Голосовое задание | Расшифровка → явное описание бренда/артикула/действия/срока → Да/исправление/отмена | Без подтверждения задача не запускается; неоднозначные поля уточняются |
| 4. Пространства и источники | Отдельно GEFU, VALIRA и проект 12520; источники и документы; исключить дублирование | Материал содержит правильную марку и артикул |
| 5. Черновики и календарь | Задания подготовки по расписанию; карточка готовой версии; проверка конфликтов | Нет ответа — нет поста; изменение версии требует нового разрешения |
| 6. Публикация | Разрешённая площадка, одобренная версия, защита от повторов, повтор изменяемых проверок | Ссылка и запись выполнения; при сбое уведомление |
| 7. CRM/лендинг/SEO | Выбрать сервисы, проверить клиентские данные/условия покупки, пройти тестовую заявку | Источник, марка, товар и статус заказа сохраняются |
| 8. Расширение | Новая площадка или марка по одной; отдельный бюджет и период | Отдельный результат и решение о продолжении |

## Первая ручная инструкция: регистрация бота
1. Telegram: найти официальный @BotFather, проверить имя и отметку верификации.
2. Нажать Start и отправить /newbot.
3. Название: «Панорама управление».
4. Username: panorama_owner_control_bot. Если занят — подобрать другое заканчивающееся на bot, согласовать итоговое имя.
5. Токен сохранить отдельно, не присылать в этот чат и не включать в GitHub.
6. Открыть созданного бота, нажать Start. До подключения программы ответ может отсутствовать.
7. Сообщить @имя. Далее выбираем сервер.

## Проверки пилота
Неверный бренд, неизвестный артикул, неясная дата, чужой Telegram ID, неподтверждённый пост, просроченная цена, изменённая одобренная версия, повторный запуск публикации и ошибка площадки должны иметь явный безопасный исход и журнал.
