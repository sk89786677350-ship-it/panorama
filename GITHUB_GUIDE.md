# Как открыть и сохранить ПАНОРАМУ на GitHub

Репозиторий: https://github.com/sk89786677350-ship-it/panorama
Это закрытый репозиторий владельца, уже существовавший до обновления 8 октября 2026 года. Новые требования сохраняются здесь, без создания дубля.

## Проверить сохранение
1. Войти в GitHub под своим аккаунтом sk89786677350-ship-it.
2. Открыть ссылку репозитория.
3. Выбрать вкладку Code, ветку main.
4. Открыть PROJECT_DECISIONS.md — здесь сегодняшние договорённости.
5. Открыть LEGAL_CHECKLIST.md — упрощённая юридическая инструкция.
6. Последние изменения и их даты видны в истории commits.

## Сохранить копию на Windows 10
1. На странице репозитория нажать Code.
2. Выбрать Download ZIP.
3. Сохранить архив и распаковать в обычную папку.
ZIP — снимок; дальнейшие изменения на GitHub не появятся в нём автоматически.

## Сохранить дальнейшее изменение через сайт
1. Открыть нужный текстовый файл.
2. Нажать значок карандаша, изменить текст.
3. Нажать Commit changes.
4. Указать понятное описание изменения.
5. Для собственного документа можно сохранить непосредственно в main; для значительной разработки использовать отдельную ветку и проверку.
6. Проверить, что в файле видна новая версия.

## Следующий шаг проекта
Создание Telegram-бота описано в NEXT_STEPS.md. Каждое действие выполняем по очереди вместе с помощником.

Никогда не загружать токен бота, пароли, .env с секретами, клиентские базы или документы с лишними персональными данными.
Режим Private не означает доступ только одному человеку: проверить Settings → Collaborators и выданные интеграциям права. Текущая работа не выполняла полный аудит доступов.
